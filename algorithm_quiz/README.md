# 识题：算法分类选择题库

本题库包含 1,000 道选择题、14 个分类。每轮最多抽 20 道不重复的到期题，选项会随机打乱。答题页默认读取 LeetCode 官方完整题面，包含正文、全部示例及解释、提示/约束和配图，不使用压缩摘要替代原题。

## 推荐入口：自动保存个人文件

双击 **`启动题库.command`**。需要本机已有 Node.js 22 或更新版本，无需安装任何包。启动后会打开 `http://127.0.0.1:8765`，保持终端窗口运行即可使用；按 Control+C 停止。

- 每题打开时获取官方完整题面，首次需要联网，成功后自动缓存。原题可能有多种方法，请结合选项和训练目标识别。
- 每题选择后点 **“提交本题”**，立即弹出对错、正确分类及原因。
- 错题自动记录，后续优先抽取，刷新或关闭重开后仍保留。
- 正确答案从提交时间起暂停抽取 **7×24 小时**，到期后自动恢复。
- 错题重新答对后，转入同样的 7 天暂停期；可以点“重做本题”重新作答。
- 不足 20 道到期题时只出实际可练的数量；全部答对且未到期时显示暂无题目，不拿暂停题补数。
- 已提交题目在本轮中仍可回顾；刷新后若停在已答对题，会转到尚未提交的题。整轮提交完后刷新会开启新轮，并排除暂停题。

### 本机个人文件

`personal/` 目录下的这些文件会自动创建并更新：

| 文件 | 内容 |
| --- | --- |
| `profile.json` | 完整存档：答题进度、历史、错题状态和复习时间；恢复以此为准 |
| `mistakes.json` | 尚未答对的错题、最后选择、错题次数和题目摘要 |
| `review_schedule.json` | 已答对题目的下次允许抽取时间 |
| `history.json` | 每次实际提交的答案、时间和对错 |
| `profile.json.bak` | 上一次完整存档备份 |
| `question_content/<slug>.json` | 该题官方完整正文 HTML、标题、来源和获取时间，按题打开后缓存 |

这些文件及临时文件全部在 Git 忽略目录中，不会随普通 `git add` 或 push 上传。页面、题库、抓取脚本中不嵌入任何个人答题数据。完整题面缓存同样仅保存在个人目录，不会混入通用 CSV 或 HTML。

浏览器也保存一份记录；本地文件与浏览器备份会按提交编号合并去重。文件保存失败时页面会提示，不会将未保存误报为成功。存档格式损坏时服务会停止，保护原文件；可先保留损坏文件，再将有效的 `profile.json.bak` 复制为 `profile.json` 后启动。

### 直接打开 HTML

双击 `index.html` 仍可使用内置备用摘要答题，支持逐题反馈、错题记录与 7 天暂停，但这时受浏览器权限限制，**不能自动读取本机完整题面缓存，也不能自动改写个人文件**。要阅读完整题面，请使用 `启动题库.command`，或点击每题始终可见的官方原题链接。记录保存在当前浏览器，可用“导出个人记录”下载完整 JSON，换浏览器时用“恢复个人记录”合并恢复。浏览器若禁止本地存储，页面会提示及时导出。

只导入 `profile.json` 或页面导出的完整个人 JSON；`mistakes.json`、`history.json`、`review_schedule.json` 为查看用的派生文件，不能单独恢复完整记录。

## 文件和来源

- `index.html`：自包含答题页，不加载外部脚本、字体或样式库。
- `question_bank.csv`：1,000 道选择题，包含题意或索引提示、示例、选项、答案、分类、解析及来源。
- `leetcode_public_index.csv`：3,700 条公开题目的元数据索引，尚未全部整理成选择题，不能直接导入答题页。
- `question_bank.json`、`leetcode_index.json`：构建数据，不包含个人记录。
- `tools/`：构建、抓取、复习规则、本地存档服务及测试。页面与复习规则为原生 JavaScript；存档服务只使用 Node 内置模块，无第三方依赖。

公开目录在 2026-11-06 抓取，返回 4,489 条记录，其中 3,700 条为非会员题。1,000 道答题记录均读取并核实公开题面。原有 493 道记录保留；新增 507 道按实时官方算法标签筛选，并对混合技术题补充人工复核。103 道使用自编示例，其余 897 道提取公开输入输出。新增题的 CSV 提供原题索引提示，完整题意在答题页阅读。通用 CSV 中仍保存摘要与一个示例；答题页会从官方读取完整正文。完整正文按每题打开时获取，并非预先把 1,000 道原文打包进 HTML；已获取的文字内容可从本机缓存读取。配图使用官方图片地址，离线可见性取决于浏览器图片缓存。

分类是当前指定的训练方向，并非“官方唯一解法”。需要时摘要约定复杂度或训练方式。官方标题和完整题面在答题前展示，官方标签及分类解析在提交后展示。若完整题面读取失败会明确提示，并提供重试按钮及官方链接；备用摘要折叠显示。

## CSV 格式与扩充

CSV 采用 UTF-8 BOM 编码，支持逗号、双引号和换行。核心字段：

| 字段 | 含义 |
| --- | --- |
| `id`、`title`、`difficulty` | 原题编号、标题、难度 Easy / Medium / Hard |
| `statement` | 中文摘要及训练目标 |
| `example_input`、`example_output`、`example_note` | 示例输入输出及来源说明 |
| `option_a` 至 `option_d` | 四个不同分类 |
| `answer`、`category` | 固定选项对应的答案字母和正确分类，两者必须一致 |
| `explanation` | 分类理由 |
| `source_url`、`source_tags`、`slug` | 官方链接、标签及标识 |
| `fetched_at`、`content_note` | 获取时间与整理说明 |

“导入 CSV”合并到当前打开的题库，相同题号更新、不同题号新增；少量错题 CSV 也可导入。导入不会清除个人答题记录。题库导入仅在本次页面打开期间有效，需长期修改时更新构建数据再构建。

## 重新抓取与构建

在本目录运行以下命令。抓取使用公开接口，顺序请求、每次暂停 200 ms；临时失败退避重试，不访问会员题面或绕过限制。

```sh
node tools/fetch-index.mjs > leetcode_index.next.json
mv leetcode_index.next.json leetcode_index.json
node tools/expand.mjs --target 1000 > question_bank.next.json
mv question_bank.next.json question_bank.json
sh tools/build.sh
```

增量扩充可将 `--target 1000` 调整为更大数量；工具保留已有题目，只追加能核实公开题面、标签和示例的记录，规则或目录变化只记录待复核提醒，不会删题。精确的归并/快速选择标签及经过核实的字符串匹配题优先补充，其余自动候选需仅对应一个现有算法分类，并排除辅助技术误判。人工添加题目仍可编辑 `tools/extra-catalog.mjs` 后运行 `tools/extend.mjs`，该工具同样保留增量题目。构建与扩充不会读写 `personal/`。


测试还检查扩充时保留旧题、避免会员题/重复题/辅助标签误分类，以及题库指纹变化后不丢错题和复习时间。测试覆盖即时判分、重复提交去重、错题优先、7 天到期边界、少于 20 道题、刷新恢复、JSON 备份合并、CSV 兼容，以及磁盘写入/重启恢复、并发记录合并和损坏文件保护，还覆盖完整题面保留、多示例/约束保留、磁盘缓存恢复、会员内容拒绝、取消离开题目的请求及包含排队时间的读取超时。测试文件使用 Node 原生测试接口；服务测试使用系统临时目录，不污染个人文件。
